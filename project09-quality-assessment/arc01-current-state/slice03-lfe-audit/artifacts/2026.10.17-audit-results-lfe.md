## Correctness and runtime safety

### LFE-001 — Concurrent evaluations receive each other's replies

**Severity:** High. **Scale:** logical unit/app. **Location:** `src/xrepl-session.lfe:175–177,222–260`.

Each new call overwrites the sole pending `From`, while evaluator messages carry no request reference. Neutral public-path probe starts a250ms first evaluation, waits until pending state is populated, then starts another caller: caller B receives `{ok,first}` and caller A times out at5000ms; second result is discarded. Sequential controls return3 and5. Keep a reference/From queue with each evaluator request/result, or reject overlapping work with an explicit busy result. Validate concurrent successes/errors/switches and late replies, preserving state/result attribution.

### LFE-002 — Evaluator stack grows on every successful evaluation

**Severity:** High. **Scale:** function/app. **Location:** `src/xrepl-session.lfe:341–362`.

Recursive calls inside the protected `try` body retain exception frames. `evaluator-stack.escript` performs500 successful public arithmetic evaluations; evaluator `stack_size` is9,909,1809,2709,3609,4509 words at0/100/200/300/400/500 calls. This is unbounded growth in the ordinary long-lived REPL. Compute a bounded outcome/state under `try`, then recurse outside its protected body; verify stack stays bounded across successful, error and switch turns. No node-exhaustion experiment was run.

### LFE-003 — Graceful close loses state newer than the last snapshot

**Severity:** High. **Scale:** lifecycle. **Location:** `src/xrepl-session-manager.lfe:77–96`; `src/xrepl-session.lfe:290–295,428–436`.

Close stops the process without saving, and termination only kills the evaluator. The60s save check happens after evaluation rather than on a periodic timer. Public probe binds12345, closes/reopens immediately, and gets unbound-symbol; explicit save then close/reopen restores67890. Save the last committed shell state before graceful close and propagate save failure, with a policy for pending evaluations. Keep explicit-save and close-without-save controls distinct. This does not assert disk persistence or closure serialization.

### LFE-004 — Expiry deletes bookkeeping while leaving the live session running

**Severity:** High. **Scale:** lifecycle/app. **Location:** `src/xrepl-store.lfe:443–472`.

Cleanup merely logs the live process before deleting its store row. Neutral probe forces an isolated session's timeout negative through public update API, calls public cleanup, and observes count1, lookup not-found, active true and eval11. Registry/evaluator resources remain while metadata vanishes. Move expiry orchestration to the lifecycle owner and ensure stop/delete agree without a synchronous store→manager→store deadlock. Include history/resource cleanup when history is enabled; that history consequence was inspected statically, not exercised against files.

### LFE-005 — Unbounded sessions and unknown item names mint permanent atoms

**Severity:** High. **Scale:** app/boundary. **Location:** `src/xrepl-session.lfe:116–126`; `src/xrepl-history.lfe:20–30`; `src/xrepl-store.lfe:437–441`; `src/xs-engine.lfe:366–368`.

Every generated/provided session ID is converted to registered-process/history-table atoms; story `take/get` converts arbitrary target text to an atom before checking any item. Closing sessions cannot reclaim those atoms. This is a source-supported node-exhaustion risk; no exhaustion attack was run. Use binary IDs and PID/registry lookups, and match item text against declared IDs without minting unknown atoms. Dispatcher `list_to_atom key` uses fixed internal key strings and is not classified as this same unbounded external-input source.

### LFE-006 — UTF8 is reinterpreted as codepoints at multiple live boundaries

**Severity:** High. **Scale:** cross-language/transport. **Location:** `src/xrepl-dispatcher.lfe:115–121,339–349`; `src/xrepl.lfe:251–257`.

Formatted UTF8 binary becomes a byte list and is then Unicode-encoded again; local printer repeats a byte-list conversion. Wire code is decoded with `binary_to_list` before the LFE reader. Probe shows an emdash `<<226,128,148>>` becomes `<<195,162,194,128,194,148>>`, and wire `(length "λ")` returns2 instead of1. Keep valid formatted binaries intact, decode wire source to codepoints once, and write binaries directly at output. Protect this with real dispatcher/reader/printer tests, not engine byte-presence tests alone.

### LFE-007 — Incomplete local input crashes the reader before multiline handling

**Severity:** High. **Scale:** user entrypoint. **Location:** `src/xrepl-io.lfe:34–47,67–78`; caller `src/xrepl.lfe:177–190`.

`lfe_io:read_string` returns a two-tuple error; both local reader branches match three-tuples. Synthetic IO probe of public read-expression with `((` raises case_clause rather than entering multiline input. The REPL loop has no catch around this read and runs in a bare spawned process. Match the actual reader contract, distinguish incomplete from invalid input, and exercise multiple lines through the public IO boundary. The fixed default-shell parser does not fix this earlier local reader.

### LFE-008 — Story commands are truncated locally and parsed forms still crash normalization

**Severity:** High. **Scale:** local reader/shell integration. **Location:** `src/xrepl-io.lfe:34–39`; `src/xrepl.lfe:177–181`; `src/xs-shell.lfe:247–254`.

Public reader probe: raw `go back` yields `{ok,go}` and `take key` yields `{ok,take}`; only parenthesized `(go back)` produces a list form. Then public xs-shell eval of `[go,back]` raises badarg at list_to_binary, while string go-back and atom back controls reach the neutral ending. Historical Slice07's assertion that raw multiword lines arrive as list forms is incomplete. Preserve raw input for non-LFE shells and normalize supported parsed forms explicitly; verify through the real local input boundary with a synthetic bundle. A list-form-only patch leaves raw truncation unresolved.

### LFE-009 — Successful graphics rendering crashes the xrepl wrapper

**Severity:** High. **Scale:** sibling API boundary. **Location:** `src/xrepl-client-shell-fns.lfe:47–50`; resolved `../term/src/xrepl-term-graphics.lfe:124–137`.

Wrapper accepts atom ok, but resolved renderer succeeds with `{ok,displayed}`. Neutral twelve-byte file plus forced-iTerm2 renderer and synthetic IO sink returns that success, followed by wrapper case_clause. Accept the resolved success contract and test it with a synthetic IO sink, plus a no-graphics control. No real paintings, terminal or hardware were used; this does not diagnose the historical hang itself.

### LFE-010 — Network intake has no configured packet bound or enforced declared limits

**Severity:** High. **Scale:** service boundary. **Location:** `src/xrepl-tcp-handler.lfe:36–38`; `src/xrepl-net-sup.lfe:46–48`; `src/xrepl.app.src:25–27`.

Packet4 framing lacks packet_size, so a peer may deliver a very large frame before token validation. Declared rate_limit/max_connections have no readers; require_auth is not a live policy toggle (TCP authentication is always attempted, UNIX peers preauthenticate). Set/validate a frame ceiling before auth and wire documented resource limits into the actual listener/handler, or clearly remove unsupported settings. Source-supported risk only: no oversized packet allocation or real listener/auth experiment was performed. Do not repeat the older audit's stronger claim that sending just a prefix immediately allocates4GiB.

## API and contract failures

### LFE-011 — Session creation discards caller metadata

**Severity:** Medium. **Scale:** public API. **Location:** `src/xrepl-session-manager.lfe:52–65`.

The API documents metadata but replaces it with a new shell/name/transport map. Probe requests neutral_custom=true and reads back only shell. Merge caller metadata with authoritative infrastructure fields before starting the process, testing preservation and reserved-key precedence. Store-only metadata tests bypass the failing manager boundary.

### LFE-012 — Hex-looking session names are interpreted as IDs

**Severity:** Medium. **Scale:** session API. **Location:** `src/xrepl-session-manager.lfe:335–368`; `src/xrepl-commands.lfe:239–268`.

Any hexadecimal-parsable name skips name resolution. Probe creates face, switch(face) returns not-found, real ID attach succeeds. Resolve an existing ID explicitly or validate full ID shape and then check names; apply the same rule in both manager and command wrapper. Test short hex names and genuine IDs.

### LFE-013 — Public APIs call missing LFE functions and literal module mod

**Severity:** Medium. **Scale:** module/dependency boundary. **Location:** `src/xrepl-env.lfe:587–595`; `src/xrepl-eval.lfe:37,246`; `src/xrepl-io.lfe:142`; `src/xrepl-shell-fns.lfe:218`; fork `src/lfe_xrepl.erl:209–221`.

Public get-bindings raises undef for lfe_env:get_vbindings; snapshot's corrected get_vars does not repair that API. LFE2.2 exports no lfe_lib:format_exception/6, so live evaluators fall back and lose intended formatting. `(: mod ...)` calls literal module mod; loaded xrepl module report incorrectly says not loaded. Xref corroborates all these calls. Use supported LFE APIs, genuine dynamic `call` where required, and test reachable exports/error reporting. Treat local-unused warnings separately from caller-reachable undef calls; fork report_exception is outside the ordinary xrepl evaluator path.

### LFE-014 — Network client assumes every done result has a value

**Severity:** High. **Scale:** network/session integration. **Location:** `src/xrepl-client.lfe:131–136`; `src/xrepl-dispatcher.lfe:104–112`.

Session commands return done plus action switch/switch-to-other and may omit value. Client eval unconditionally maps:get(value) and ignores action/session, so ordinary remote session management can raise badkey. Handle the protocol's action variants explicitly and preserve session selection. This is source-supported; no network listener replay was run. Also inspect response IDs before attributing a synchronous reply; current eval/ping/clone do not correlate them.

### LFE-015 — Valid MessagePack values and wrong field types bypass schema validation

**Severity:** Medium. **Scale:** wire boundary. **Location:** `src/xrepl-tcp-handler.lfe:84–120`; `src/xrepl-dispatcher.lfe:252–255,153`.

Codec returns any decoded term, but auth/dispatcher assume maps and binary token/session values. Public dispatcher probe with integer42 raises badmap, while unknown-op map returns a structured error. Valid scalar/array MessagePack is therefore distinct from the existing malformed-bytes regression. Validate request shape/types before authentication/dispatch and return a bounded protocol error. Current probe proves dispatcher behavior; handler disconnection follows from source inspection, not a socket test.

### LFE-016 — History ownership and privacy options do not match lifecycle

**Severity:** High. **Scale:** app/client/file boundary. **Location:** `src/xrepl-history.lfe:280–306,115–132`; `src/xrepl-client-shell.lfe:65–72,170–212`; `bin/xrepl:130,271,285,361`.

Each session spawns an unlinked saver watching global user, not its session, and uses the same history path/temp filename. Session close deletes its owned ETS table before that eventual save; concurrent savers can clobber shared files. Separately, client init unconditionally reads/uploads the default history path, and rlwrap is passed its history file even with --no-history; client/history options are not threaded into this startup path. These are source-supported risks, not reproduced using personal files. Tie persistence to explicit lifecycle ownership and make history disable/custom path apply consistently to client upload and rlwrap; test solely with isolated temporary histories and concurrent sessions.

### LFE-017 — Session configuration stores values that live behavior ignores

**Severity:** Medium. **Scale:** app policy. **Location:** `src/xrepl-config.lfe:16–26,47–51`; `src/xrepl-session.lfe:138–144,168,428–436`; `src/xrepl-history.lfe:158–164`; `src/xrepl.lfe:372–397`.

Config exposes prompt/history/max-history/save-interval/auto-save, but session startup reads global history options, save interval is fixed60000, history trimming fixed1000, and prompt builds its own label. Tests assert store/get roundtrips, not resulting behavior. Establish one applied config owner, wire supported options, and label/remove unsupported settings. Do not claim this is a demonstrated timing failure; the source shows the settings are not consumed at their execution sites.

### LFE-018 — Tests exercise substitutes and ambient files instead of claimed boundaries

**Severity:** Medium. **Scale:** test/codebase. **Location:** `test/xrepl-shell-lfe-tests.lfe:202–221`; `test/xrepl-multi-session-tests.lfe:43–65`; `test/xs-engine-tests.lfe:482–506`; `test/xs-bundle-tests.lfe:246–286`; `test/xs-shell-tests.lfe:227–238`; `.github/workflows/cicd.yml:35–47,69–78`.

A snapshot-restore test passes the live env directly, concurrent-sessions runs sequentially across different sessions, Unicode shell tests stop before dispatcher/printer, and image-warning tests assert load/fetch rather than warning presence. The xs-run absent-file test accepts real-archive loading and thus depends on ambient priv contents; coordinator confirms the archive is present, so native175/175 cannot be described as synthetic-only or archive acceptance. Many session setups leave real history enabled. Preserve useful unit tests, add public-boundary regressions and isolate fixtures; retain native receipt limitations. Xref is available through make lint but CI and rebar check still omit it; blanket historical 'no static gate' is stale.

### LFE-019 — Engine totality and text claims exceed implementation

**Severity:** Medium. **Scale:** pure engine/API. **Location:** `src/xs-world.lfe:186–243`; `src/xs-engine.lfe:30–36,70–75`; `src/xs-bundle.lfe:21–23,335–347`.

Public eval-cond with improper `(and . tail)` crashes foldl, and render-element([8212]) passes string? then crashes list_to_binary despite the docstring accepting codepoints. A synthetic bundle with undeclared on-enter flag loads and mutates it; original flag-reference validation remains deferred in bundle, with no world validation implementation. Make condition/text/bundle acceptance explicit and validate once at the edge. Test malformed grammar, nonboolean flag defaults and UTF8/codepoint distinctions; the normal byte-list path is a passing control, not proof of totality.

### LFE-020 — Launcher option plumbing contradicts visible behavior

**Severity:** Medium. **Scale:** executable/configuration. **Location:** `bin/xrepl:271,401–405,428–432`; `src/xrepl.lfe:81–117`; `src/xrepl-net-sup.lfe:112–116`.

Launcher sends banner key while start reads banner?, so --no-banner cannot control that branch. Hybrid mode unconditionally asks auth for a token before choosing UNIX when TCP is disabled, but auth child starts only with tcp_enabled=true. Use the consumer's real key and query a token only for TCP. These are source-supported, not boot-smoked here because real listeners/auth/files are excluded. `sh -n` passes and does not validate these semantics.

## Coherence and cross-language observations

Request IDs exist on the wire but the LFE client does not use them to demultiplex; the session evaluator needs its own correlation regardless of wire IDs (LFE-001/014). Boundary text policy is inconsistent: terminal adapter writes binaries correctly, while live local printer and dispatcher reinterpret bytes (LFE-006); engine tests correctly preserve UTF8 bytes but stop too early. Save ownership is split between environment snapshots and xs metadata, intentionally with in-VM rather than cross-VM persistence; those documented deferrals must remain separate from graceful-close loss and expiry defects.

`xs-shell` module text still says images/save are deferred even though code implements both (`src/xs-shell.lfe:1–13,304–322`); several old command names in README/remote help differ from bound sesh-/hist names. These are documentation observations for later reconciliation. Erlang snake_case and LFE hyphen naming are established language conventions and are not correctness findings. Specs are largely absent in LFE, but the fork does contain two specs: historical 'no specs anywhere' must be narrowed. No formatting sweep, new language floor or replacement architecture is recommended by this audit.

2. Searched tracked LFE/Erlang source for binary_to_term: none. Codec boundary uses MessagePack, not unsafe Erlang term deserialization. This does not establish schema validation (LFE-015).
3. Snapshot now uses real lfe_env:get_vars and explicit save→close→reopen restores67890 in the public probe (`src/xrepl-shell-lfe.lfe:144–157`). This clean path does not excuse close-without-save loss.
4. Story ending clears the save slot to none, avoiding incorrect removal through merge-only metadata API; neutral ending probe confirms it (`src/xs-shell.lfe:314–322`). Do not file a nonexistent map-removal bug.
5. No live binary:join calls remain under src/test; three matches are comments/docstrings. Portable lists:join+iolist conversion is implemented (`src/xs-shell.lfe:293–298`, history121).
6. Active-shell metadata is prepared before process startup (`src/xrepl-session-manager.lfe:55–67`), fixing the historical timing problem. Caller-metadata preservation is a separate defect.
7. Temporary session children are bounded-shutdown workers and child supervisors use infinity shutdown (`src/xrepl-session-sup.lfe:68–77`, `src/xrepl-sup.lfe:66–84`). No permanent restart of deliberately closed session workers found.
8. Error-rearm path uses dynamic call and immediately rearms active-once; unsolicited idle keepalive clause is absent (`src/xrepl-tcp-handler.lfe:58–110`). Existing coordinator suite covers these regressions; no gratuitous31s rerun here.
